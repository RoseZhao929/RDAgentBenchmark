\subsection{B.1 Overview}\label{b.1-overview}

Every baseline in our lineup is replicated using one of two protocols:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Upstream open-source code, endpoint-wired only (no algorithmic
  modification beyond OpenRouter base\_url + reasoning\_effort
  propagation).
\item
  Strict paper-faithful re-implementation when upstream is unavailable
  or has un-resolvable license restrictions.
\end{enumerate}

All adapter shims are released under Apache 2.0. Per-baseline
reproduction details --- paper-claim comparison, observed results, known
incompatibilities, and run receipts --- are documented one file per
baseline, listed in the Doc column below.

\subsection{B.3 Setup-mismatch documentation (the gap stories)}\label{b.3-setup-mismatch-documentation-the-gap-stories}

\textbf{MAI-DxO -38 pp}: Paper input = narrative-rich NEJM clinicopath
case (\textasciitilde2,000 words). Our input = HPO-list + 1--2 sentence vignette.
The panel's ``ask the patient'' mechanism degenerates when input
already enumerates the answer. Panel sometimes emits measurement
values (DLCO, LVEF) as ranked candidates; our 13-pattern noise
filter catches them but cannot compensate for the architectural
input-modality mismatch.

\textbf{DeepRare -29 pp on HPO-only / -33 pp on HPO+variants}:
- Web search disabled (\texttt{DEEPRARE\_NO\_WEB=1}) for contamination control ---
paper enables full RAG.
- Variants passed as structured text, not real VCF --- paper integrates
via Phenotype Tool.
- Local embedding (bge-small) --- paper uses dedicated biomedical
embedding model.
- Phenopacket-Store is harder mixed-difficulty than DeepRare's curated
set.

\textbf{VC-RDAgent +16 pp over paper}: We use Stage 1 only (offline IC +
Poincar\'e, no LLM), which the paper reports as 0.27 on Phenopacket-
Store. We observe 0.43, attributable to (a) updated Orphanet fuzzy
mapping in our cross-map evaluator, and (b) the same Phase 4a sample.

\subsection{B.4 Behavior-changing patches surface}\label{b.4-behavior-changing-patches-surface}

\begin{quote}
The following changes affect baseline behavior. All other patches
are endpoint-wiring only.
\end{quote}

\textbf{DeepRare} --- \texttt{agents/deeprare/diagnosis.py} + \texttt{diagnosisGene.py}:
adapter-side fallback regex \texttt{r\textquotesingle{}\^{}\#\#\textbackslash{}s+(.+?)\textbackslash{}s*\textbackslash{}(Rank\textbackslash{}s*\#\textbackslash{}d+\textquotesingle{}} activates
when primary \texttt{r\textquotesingle{}\textbackslash{}*\textbackslash{}*(.*?)\textbackslash{}*\textbackslash{}*\textquotesingle{}} returns 0 matches. Required for GPT-5
minimal output format (no markdown bold). Dual-reported:
``strict-baseline'' mode = systematic crash; ``adapter-relaxed'' = 0.30
R@1 on the same data (footnote \Cref{sec-5-2}).

\textbf{MAI-DxO} --- \texttt{harness/agents/maidxo.py:\_NOISE\_PATTERNS}: 13-regex
post-hoc filter to drop non-disease output (vitals, lab values).
Wrapper-only modification; MAI-DxO's panel logic untouched.

\textbf{MDAgents / MedAgents / AgentClinic} --- \texttt{harness/agents/\_adapter\_utils.py:\ parse\_ranked\_top5}: section-aware regex preferring numbered list
after ``differential diagnosis'' / ``candidate'' / ``ranked top-N'' header;
prose-prefix filter rejects ``Laboratory evidence\ldots{}'', ``Progressive\ldots{}'',
etc. as clinical-feature mentions. Wrapper-only; agent's deliberation
logic untouched.

\textbf{All ID mapping (mdagents/medagents/agentclinic/maidxo/llm\_control)} ---
\texttt{map\_names\_to\_ids\_with\_variants}: returns tied top-K ORPHA candidates
per LLM-named disease (fuzzy score within 5 pts of top); evaluator
\texttt{gold\_hit\_with\_variants} accepts any of the tied IDs. Documented as ablation A4.

\subsection{B.5 Independent re-replication invitation}\label{b.5-independent-re-replication-invitation}

Any reader can reproduce a single Phase 4a cell via:

\begin{Verbatim}
python3 scripts/phase4a_runner.py \
    --dataset <phenopacket_store|rarearena_rds|rarebench> \
    --agent <baseline_name> \
    --backbone openrouter/<provider>/<model> \
    --n 100 \
    --out predictions_test.jsonl
\end{Verbatim}

The legacy aggregate receipt has 93 cell rows, including 22 obsolete MIMIC
title-task rows that are excluded from the current paper. The frozen evidence
manifest indexes 71 diagnostic cells and 12 PMC temporal-sensitivity cells.
Per-case JSONL artifacts carry request ID where available, dollar cost,
latency, and status; \texttt{scripts/phase4a\_report\_gen.py} regenerates aggregate
diagnostic summaries from those raw files. The replacement structured-EHR
task requires a separate task-versioned receipt.

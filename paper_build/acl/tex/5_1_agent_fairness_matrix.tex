\subsubsection{Three anticipated objections --- pre-empted}\label{three-anticipated-objections-pre-empted}

\textbf{Objection 1}: ``Adapter quality differences confound results.''
\textbf{Response}: All 8 adapter shims are released open-source (3,485 LOC total), each accompanied by a run report documenting its exact subprocess calls, parser logic, and known caveats. Independent re-implementation invited.

\textbf{Objection 2}: ``Different agents accept different inputs --- apples to oranges.''
\textbf{Response}: Dual-pass evaluation (gold-HPO + end-to-end, \Cref{sec-4-4}). The Pass A \ensuremath{-} Pass B delta on the same agent quantifies P1 sensitivity. RareBench Table 6 precedent --- phenotype-input vs EHR-text-input on identical model --- is the same design.

\textbf{Objection 3}: ``Mixing classical (LIRICAL) and LLM agents is unfair.''
\textbf{Response}: Standard convention --- see DeepRare (Nature 2026) which includes Exomiser / LIRICAL / AI-MARRVEL as classical baselines. We report them as separate ``Classical Baseline'' rows in \Cref{tbl:main} and do not include them in LLM-only ablations (A1/A2/A4/A5/A6/A7).

\subsubsection{Per-agent known caveats (we surface these honestly)}\label{per-agent-known-caveats-we-surface-these-honestly}

\begin{itemize}
\tightlist
\item
  \textbf{MDAgents/MedAgents/RDMA/VC-RDAgent: no license file in upstream repos}. We comply with academic fair use (run + report numbers); we do not redistribute their code. Our adapter shims are released independently (Apache 2.0). Action item filed with upstream authors as future work.
\item
  \textbf{DeepRare CC BY-NC 4.0 prevents commercial deployment} --- academic use OK; we note this in Limitations.
\item
  \textbf{MAI-DxO community port} (\texttt{Open-MAI-Dx-Orchestrator}, 58\ensuremath{\star} MIT) is structurally faithful to Nori et al.~(arXiv 2506.22405) but prompt strings and test-cost values are reimplemented from paper text --- minor numerical deviation from Microsoft's reference may exist. Documented in Methods footnote.
\item
  \textbf{AgentClinic} in our diagnostic matrix is tested on HPO-only
  Phenopacket-Store/RareBench and narrative RareArena cases. MIMIC is a separate
  structured-event probe with a common serialized input across eligible agents.
\item
  \textbf{LIRICAL} requires HPO list input. On RareArena (free text), our adapter triggers \texttt{eval\_mode="end\_to\_end"} upstream LLM HPO extraction + phrase\ensuremath{\rightarrow}HP-ID normalization. LIRICAL scores far lower on RareArena than on gold-HPO Phenopacket-Store, but that difference confounds dataset difficulty with input condition and is \emph{not} a clean extraction-penalty estimate --- see the same-case analysis and correction in \Cref{sec-7-1}.
\end{itemize}
